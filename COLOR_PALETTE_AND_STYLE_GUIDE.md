# Color Palette & Visual Style Guide

## INTRODUCTION

This document establishes the visual identity and design standards for the municipal water fault reporting video. All animators, designers, and production team members must follow these guidelines to ensure consistency, professionalism, and effective communication.

---

## PRIMARY COLOR PALETTE

**RGB**: (46, 204, 113)
**CMYK**: (77%, 0%, 45%, 20%)

## ACCESSIBILITY & CONTRAST REQUIREMENTS

### WCAG AA Compliance
All text must meet minimum contrast ratios:

**Normal Text** (below 18pt):
- Minimum contrast ratio: 4.5:1

**Large Text** (18pt+):
- Minimum contrast ratio: 3:1

### Approved Text & Background Combinations

| Text Color | Background Color | Contrast Ratio | Status |
|-----------|-----------------|----------------|--------|
| #2C3E50 (Dark Gray) | #FFFFFF (White) | 13.5:1 | ✓ Excellent |
| #2C3E50 (Dark Gray) | #F8F9FA (Light) | 12.3:1 | ✓ Excellent |
| #FFFFFF (White) | #2ECC71 (Green) | 5.2:1 | ✓ AA Compliant |
| #FFFFFF (White) | #E63946 (Red) | 4.8:1 | ✓ AA Compliant |
| #FFFFFF (White) | #3498DB (Blue) | 6.1:1 | ✓ AA Compliant |
| #2C3E50 (Dark) | #F39C12 (Yellow) | 8.7:1 | ✓ Excellent |
| #FFFFFF (White) | #95A5A6 (Gray) | 5.9:1 | ✓ AA Compliant |

### Prohibited Combinations (Fail WCAG)
- Dark text on dark backgrounds
- Light text on light backgrounds
- Pure red text on white (border recommended)
- Pure blue on pure green

## TYPOGRAPHY & FONT STYLING

### Primary Font: Montserrat (Bold)

**Sizes & Uses**:
- 96pt: Main titles, final call-to-action text
- 64pt: Scene headers, major emphasis
- 48pt: Section headings, reference numbers
- 32pt: On-screen labels, instructions
- 24pt: Body text, smaller screens

**Characteristics**:
- Bold weight for emphasis
- All-caps for major labels (REFERENCE, REPORT IT, etc.)
- Mixed case for longer text
- Generous letter spacing for readability

**Usage Examples**:
- "STOP! DON'T CREATE DUPLICATE COMPLAINTS"
- "REFERENCE: 123456789"
- "FOLLOW IT UP"

## ICON & SYMBOL STYLING

### Icon Design Principles

1. **Consistency**: All icons use same stroke weight (2-3px)
2. **Simplicity**: Easily recognizable at small sizes
3. **Color-Coding**: Green = positive, Red = negative, Blue = informational
4. **Scalability**: Vector-based, works at any size
5. **Legibility**: Clear distinction from backgrounds

### Icon Specifications

#### Warning Triangle (⚠️)
- Stroke width: 3px
- Color: #E63946 (red)
- Size variations: 24x24, 48x48, 96x96 px
- Optional: Pulsing/breathing animation
- Hover state: Slightly larger, shadow effect

#### Checkmark (✓)
- Stroke width: 3-4px
- Color: #2ECC71 (green)
- Animation: Appear with "draw" effect (stroke animation)
- Size variations: 24x24, 48x48, 96x96 px
- Variants: Checkmark only, checkmark in circle

#### Phone Icon (☎️)
- Stroke width: 2px
- Color: #3498DB (blue)
- Style: Modern smartphone shape
- Size: 32x32, 64x64 px
- Variants: Phone with notification badge

#### Clock Icon (🕐)
- Stroke width: 2px
- Color: #95A5A6 (gray) or #F39C12 (gold)
- Animation: Hands rotate for time passage
- Size: 40x40, 80x80 px
- Variants: With numbers, simplified

#### Water Droplet (💧)
- Stroke width: 2px
- Color: #3498DB (blue)
- Style: Realistic water appearance
- Size: 32x32, 64x64 px
- Variants: With particles for splash effect

#### Reference Number Icon
- Shape: Rectangular box with rounded corners
- Stroke: 2px border (#F39C12)
- Fill: Light yellow (#F39C12) at 20% opacity
- Text: Dark gray centered inside
- Size: Flexible to fit reference number

## BACKGROUND & LAYOUT SPECIFICATIONS

### Video Background Canvas
- **Primary Background**: #F8F9FA (light gray)
- **Alternative Background**: #FFFFFF (pure white)
- **Texture**: Flat, minimal (no patterns)
- **Opacity**: Fully opaque (100%)

### Content Area Layout
- **Safe Area**: 90% of screen (10% margin on all sides)
- **Text Area**: Center-aligned for maximum readability
- **Element Spacing**: Minimum 16px between major elements
- **Padding**: 24-32px inside containers

### Border & Outline Specifications
- **Standard Border**: 2px solid
- **Emphasis Border**: 3px solid
- **Border Colors**: 
  - Green borders for correct/positive
  - Red borders for warnings/incorrect
  - Blue borders for informational
  - Gray borders for neutral

### Shadow & Depth Effects
- **Subtle Shadow**: 0 2px 8px rgba(0,0,0,0.1)
- **Emphasis Shadow**: 0 4px 12px rgba(0,0,0,0.15)
- **No Heavy Shadows**: Keep professional, clean appearance
- **Shadow Color**: Always dark gray/black, never colored

---

## ANIMATION & TRANSITION COLORS

### Fade Transitions
- Fade out: Transition to #F8F9FA or #FFFFFF (background color)
- Fade in: Appear from background color
- Duration: 0.5-1 second

### Color Shifts (for emphasis)
- Slow shift from gray to green: Indicates correct action
- Quick flash to red: Warning/mistake indication
- Pulse effect: Color intensifies, then fades, then repeats

### Text Animation
- **Appear**: Fade in over 0.3 seconds
- **Emphasis**: Brief highlight color flash
- **Disappear**: Fade out over 0.5 seconds
- **Color during animation**: Always maintain high contrast

## REFERENCE NUMBER DISPLAY STANDARD

### Format & Appearance
- **Format**: "REFERENCE: 123456789"
- **Font**: Montserrat Bold, 48pt minimum
- **Text Color**: Dark gray (#2C3E50)
- **Background Box**: 
  - Fill color: #F39C12 (gold)
  - Border: 3px solid #F39C12
  - Rounded corners: 8-12px radius
  - Padding: 12-16px on all sides

### Sizing Options

| Context | Font Size | Box Size | Usage |
|---------|-----------|----------|-------|
| Large Emphasis | 48pt | 600x80px | Scenes 1, 5, 6 - initial/follow-up |
| Standard Display | 36pt | 480x70px | Timeline elements, mid-scene |
| Small Reference | 24pt | 300x50px | Multiple references, packed display |
| Mobile Optimized | 32pt | 400x60px | WhatsApp/mobile viewing |

### Color Variations by Context
- **Original (Correct)**: Gold box (#F39C12) with green checkmark
- **Duplicate (Incorrect)**: Red box (#E63946) with red X or warning triangle
- **Following Up**: Green highlight on gold box
- **Escalated**: Blue highlight on gold box

### Placement Guidelines
- **Primary Scene**: Top-center or center of screen
- **Timeline**: Aligned with milestone marker
- **Multiple References**: Stacked vertically, slightly offset for 3D effect
- **Final Emphasis**: Large, centered, with strong shadow

## EMOTION & CHARACTER COLOR PSYCHOLOGY

### Character Clothing Color Recommendations
- **Scene 1 (Concern)**: Neutral or cool colors (blues, grays, greens)
- **Scene 2 (Impatience)**: Same clothing, but character expression changes
- **Scene 3 (Frustration)**: Optional red accent or warm tones
- **Scene 5-9 (Confidence)**: Maintain consistent clothing but with satisfied expression

### Emotional Color Association
- **Green**: Confidence, resolution, relief, positive action
- **Red**: Frustration, warning, mistake, need for caution
- **Blue**: Professional, authoritative, calm communication
- **Yellow/Gold**: Attention, importance, highlighting key information
- **Gray**: Neutral, waiting, patience, quiet anticipation

## PRINT & EXPORT COLOR SPECIFICATIONS

### Web/Digital
- **Color Space**: sRGB
- **Gamma**: 2.2
- **Profile**: sRGB IEC 61966-2.1

### Video Codec
- **Color Space**: Rec. 709 (ITU)
- **Color Range**: Full (0-255)
- **Chroma**: 4:2:0 (H.264 standard)

### Export Specifications
- **Master File**: ProRes 422 HQ (maintains full color)
- **Web Files**: H.264 with 4:2:0 chroma (standard)
- **Mobile Files**: Same color space, optimized bitrate

## COLOR TESTING & QUALITY ASSURANCE

### Before Final Export
- [ ] Test all colors on multiple monitors/displays
- [ ] View on mobile phone (smallest screen size)
- [ ] Verify contrast ratios with accessibility tools
- [ ] Check for color blindness issues (using simulator)
- [ ] Confirm colors match approved palette exactly
- [ ] Test video in bright/dark environments

### Accessibility Color Testing
- Use tools like WebAIM Contrast Checker
- Test for Deuteranopia (red-green colorblindness)
- Test for Protanopia (red-blind)
- Test for Tritanopia (blue-yellow colorblindness)
- Ensure message is clear without relying on color alone

### Color Consistency Check
- Reference number boxes: All same gold shade
- All green checkmarks: Same shade of green
- All warning symbols: Same shade of red
- Backgrounds: Consistent light gray throughout

## FINAL NOTES FOR DESIGN TEAM

1. **Color Consistency is Critical**: Use hex codes provided, not RGB approximations
2. **Test Early**: Export early versions and view on actual devices
3. **Accessibility First**: Always maintain WCAG AA compliance
4. **Emotion Matters**: Color choices reinforce the emotional journey
5. **Keep It Simple**: Stick to the 5 primary colors + neutrals
6. **Mobile Optimization**: Colors must work on small, bright phone screens
7. **Print Preview**: Even for digital-only, test print appearance for reference
8. **Document Changes**: If any colors are adjusted, update this guide
