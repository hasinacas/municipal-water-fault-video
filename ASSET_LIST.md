## NOTES FOR PRODUCTION TEAM

- **Simplicity First**: Prioritize character expressions and text clarity over background details
- **Mobile Testing**: Test all graphics and text at 1080p and scaled down sizes
- **Consistency**: Use the same reference number format throughout (REFERENCE: 123456789)
- **Timing**: Lock all animation timing to voiceover—don't guess on pacing
- **Backup**: Keep version control of major revisions
- **Communication**: Weekly check-ins with client/stakeholder for alignment
- **Accessibility**: Ensure all text is readable, all colors have sufficient contrast
