# Scene-by-Scene Production Script & Specifications

## VIDEO OVERVIEW
- **Total Duration**: 3-4 minutes
- **Target Audience**: All South African residents (ages 16+)
- **Platform**: WhatsApp, YouTube, Facebook, Instagram, TikTok
- **Style**: Clean 2D flat design, professional, friendly but serious
- **Aspect Ratios**: 16:9 (primary), 9:16 (vertical for social media)

---

## SCENE 1: THE PROBLEM (20-25 seconds)

### Visual Description
- **Setting**: South African residential area - suburban home with visible water leak/burst pipe outside
- **Characters**: Resident 1 (diverse ethnicity, concerned expression)
- **Key Elements**: 
  - Water pooling or spraying from pipe
  - Resident looking worried/frustrated
  - Phone in hand
  - Municipal reference number displayed prominently

### Animation Sequence
1. **0:00-0:03** - Fade in: Morning sun, peaceful residential street
2. **0:03-0:07** - Zoom in on water fault (leak/burst pipe) with close-up
3. **0:07-0:12** - Resident notices problem, facial expression changes to concern
4. **0:12-0:16** - Resident takes out phone, dials/contacts municipality
5. **0:16-0:20** - Phone screen shows: "Call connected to municipality..."
6. **0:20-0:25** - Large reference number appears: "REFERENCE: 123456789"
   - Resident saves number to phone (shown visually)
   - Reference number stays on screen prominently

### On-Screen Text
- **0:00** - "Water fault? Report it!"
- **0:16** - "Contact the municipality"
- **0:20** - "REFERENCE: 123456789" (large, bold, yellow/gold highlight box)

### Voiceover
"You've noticed a water fault at your home. You report it to the municipality and receive a reference number. This number is important—keep it!"

### Character Emotions
- Concern (noticing fault)
- Action-oriented (taking phone)
- Relief (contacted municipality)
- Determination (saving the number)

### Animation Details
- Water effect: Realistic but slightly stylized splash/spray
- Character animation: 2-3 frames per second (smooth but efficient)
- Transition: Fade to next scene

## SCENE 2: THE 48-HOUR CONFUSION (25-30 seconds)

### Visual Description
- **Setting**: Same residential home, interior
- **Characters**: Same resident, showing impatience
- **Key Elements**:
  - Large clock/calendar animations
  - Thought bubbles showing resident's confusion
  - Clear "48 HOURS" timer
  - Explanatory graphics

### Animation Sequence
1. **0:00-0:03** - Fade in: Resident sitting at home, looking at phone
2. **0:03-0:08** - Large calendar appears showing "DAY 1"
3. **0:08-0:12** - Clock animation spinning (24 hours passing)
4. **0:12-0:18** - "DAY 2" appears, resident looks more frustrated
5. **0:18-0:25** - Text explanation appears: "48 HOURS = TIME TO ATTEND / BE ONSITE"
   - Large graphic showing "NOT necessarily complete repair"
   - Thought bubble over resident's head showing confusion
6. **0:25-0:30** - Emphasize: "48 hours = ATTENDANCE, not COMPLETION"

### On-Screen Text
- **0:03** - "DAY 1"
- **0:12** - "DAY 2"
- **0:18** - "48 HOURS = TIME TO ATTEND TO FAULT & BE ONSITE"
- **0:24** - "NOT complete repair"
- **Highlight box** - "Still waiting? Don't panic."

### Voiceover
"The 48-hour period refers to the municipality attending to the fault and being onsite. It does NOT necessarily mean the entire problem will be repaired within 48 hours. This is the response time—not the resolution time."

### Visual Effects
- Clock/calendar animations (smooth spinning or counting)
- Transition from DAY 1 to DAY 2 with clear visual separation
- Sad/confused emoji over resident's head
- Large red X over "complete repair" text

### Animation Details
- Use bold, easy-to-read sans-serif font (e.g., Open Sans, Montserrat)
- Color coding: Gray = waiting period, Green = attendance, Red = misconception
- Resident's facial expression becomes increasingly confused/impatient

## SCENE 3: THE COMMON MISTAKE (30-35 seconds)

### Visual Description
- **Setting**: Resident's phone/home, showing multiple complaint submissions
- **Characters**: Same resident, now frustrated and impulsive
- **Key Elements**:
  - Multiple reference numbers appearing
  - Visual "piling up" effect
  - Warning symbol prominently displayed
  - Red color scheme to indicate mistake

### Animation Sequence
1. **0:00-0:03** - Resident looking very frustrated at phone
2. **0:03-0:07** - First new complaint created: "REFERENCE: 987654321" appears with "PING" sound
3. **0:07-0:12** - Time passes (visual: another day marker)
4. **0:12-0:16** - Second new complaint: "REFERENCE: 456789123" appears (PING)
5. **0:16-0:21** - Third new complaint: "REFERENCE: 321654987" appears (PING)
6. **0:21-0:30** - All reference numbers pile up on screen
   - Large warning triangle symbol appears
   - Red text: "STOP! DON'T CREATE DUPLICATE COMPLAINTS"
   - Resident's face shows regret

### On-Screen Text
- **0:03** - "I'll report it again..."
- **0:07** - "NEW COMPLAINT"
- **0:07** - "REFERENCE: 987654321"
- **0:12** - "NEW COMPLAINT"
- **0:12** - "REFERENCE: 456789123"
- **0:16** - "NEW COMPLAINT"
- **0:16** - "REFERENCE: 321654987"
- **0:24** - ⚠️ "STOP!"
- **0:26** - "DON'T CREATE DUPLICATE COMPLAINTS"

### Voiceover
"In frustration, the resident creates a new complaint. Then another. And another. Do NOT keep reporting the same unresolved problem as a new fault. Every new complaint creates a new reference number, making it impossible to track the original issue."

### Visual Effects
- Reference numbers appear with "PING" sound effect
- Numbers stack/pile up in a messy, confusing visual pattern
- Red warning triangle symbol pulses
- Resident's eyebrows furrow in regret
- Transition: Everything shakes slightly as warning appears

### Animation Details
- Use contrasting red color (#E63946 or similar) for warning elements
- Reference numbers should be in different positions (not perfectly aligned) to show chaos
- Sound effects: Notification "ping" for each new complaint
- Font: Bold, large, impossible to miss

## SCENE 4: SHOW WHAT HAPPENS (20-25 seconds)

### Visual Description
- **Setting**: Abstract visual timeline/flowchart
- **Characters**: None (or silhouettes of municipality staff)
- **Key Elements**:
  - Clear timeline showing original complaint
  - Multiple branches showing new complaints
  - Confusing arrows and overlapping paths
  - Municipality staff confused by multiple references

### Animation Sequence
1. **0:00-0:03** - Clean white/gray background appears with timeline
2. **0:03-0:08** - "DAY 1 — ORIGINAL FAULT REPORTED" appears with arrow pointing to reference number
3. **0:08-0:12** - Original reference "123456789" in green box
4. **0:12-0:18** - Branching arrows appear showing multiple NEW COMPLAINTS
5. **0:18-0:25** - Multiple new references appear in red boxes, creating messy overlapping timeline
6. **0:25-0:28** - Confused municipality staff silhouette appears, looking at tangled timeline

### On-Screen Text
- **0:03** - "DAY 1 — ORIGINAL FAULT REPORTED"
- **0:08** - "REFERENCE: 123456789" (green, original)
- **0:12** - "NEW COMPLAINT"
- **0:14** - "REFERENCE: 987654321" (red, duplicate)
- **0:16** - "NEW COMPLAINT"
- **0:18** - "REFERENCE: 456789123" (red, duplicate)
- **0:22** - "RESULT: CONFUSING PAPER TRAIL"
- **0:24** - "Hard to track when fault started"

### Voiceover
"Instead of showing one fault waiting since the original report, multiple new references make it appear as though these are separate, newly reported incidents. The original complaint gets lost in the confusion."

### Visual Effects
- Green highlighting for original complaint
- Red highlighting for duplicate complaints
- Branching arrows that overlap and tangle
- Silhouette of confused municipality worker
- Visual chaos gradually builds

### Animation Details
- Use flowchart/timeline format (very clear, easy to follow)
- Green to red color transition as mistakes increase
- Arrows should show the flow of information becoming tangled
- Timeline should move from left to right (standard reading direction)

## SCENE 5: THE CORRECT WAY (25-30 seconds)

### Visual Description
- **Setting**: Repeat of Scene 1 setting, but show correct behavior
- **Characters**: Same resident (or different resident showing best practice)
- **Key Elements**:
  - Original reference number displayed
  - Phone screen showing follow-up call
  - Resident speaking clearly about the reference number
  - Confident, calm demeanor

### Animation Sequence
1. **0:00-0:03** - Scene resets, same fault is still present
2. **0:03-0:08** - Resident pulls out phone, shows saved reference number: "123456789"
3. **0:08-0:12** - Phone screen shows: "FOLLOW UP CALL"
4. **0:12-0:18** - Resident speaks (with clear on-screen text matching words)
5. **0:18-0:25** - Text appears: "STATUS OF REFERENCE: 123456789?"
6. **0:25-0:30** - Resident gets update information, looks satisfied

### On-Screen Text
- **0:00** - "SCENE RESET: Same problem, different approach"
- **0:03** - "KEEP YOUR ORIGINAL REFERENCE NUMBER"
- **0:08** - "123456789" (green highlight box, large)
- **0:12** - "FOLLOW UP"
- **0:15** - Resident says (in speech bubble): "Hi, I'm following up on reference 123456789"
- **0:18** - "The fault is still unresolved"
- **0:22** - "Can you provide an update?"

### Voiceover
"If the fault is still unresolved after 48 hours, follow up using your original reference number. Ask for an update against the existing fault—NOT a new complaint. This keeps everything tracked under one case."

### Character Emotions
- Calm and organized
- Confident speaking to municipality
- Hopeful about resolution
- Professional demeanor

### Visual Effects
- Green color scheme (positive, correct approach)
- Same resident now appears confident/satisfied
- Phone screen clear and readable
- Checkmark or positive indicator appears

### Animation Details
- Reference number stays visible throughout scene
- Use same font/style as Scene 1 for consistency
- Clear contrast between this scene and Scene 3 (correct vs. incorrect)
- Smile on resident's face

## TEXT PLACEMENT & TYPOGRAPHY GUIDELINES

### Font Choices
- **Primary Font**: Montserrat Bold (titles, large text)
- **Secondary Font**: Open Sans Regular (body text, voiceover subtitles)
- **Size**: Minimum 24pt for readability on small screens (WhatsApp)

### Color Scheme
- **Primary Green**: #2ECC71 (correct actions, positive)
- **Warning Red**: #E63946 (mistakes, duplicates)
- **Professional Blue**: #3498DB (information, municipality)
- **Neutral Gray**: #95A5A6 (background, waiting period)
- **Text**: Dark Gray/Black (#2C3E50) for contrast

### Text Timing Rules
- Each on-screen text appears 2-3 seconds before related voiceover line
- Text stays on screen for 3-5 seconds minimum
- Reference numbers stay visible for entire duration of relevant scene
- Final message displayed for 7+ seconds

---

## TRANSITION GUIDELINES

- **Between Scenes**: 0.5-1 second fade or slide transition
- **Within Scenes**: Smooth 0.3-0.5 second transitions for animation elements
- **Text Reveal**: Appear in 0.3 seconds, fade out in 0.5 seconds

---

## AUDIO SPECIFICATIONS

- **Voiceover**: Professional South African English accent, warm but serious tone, clear diction
- **Background Music**: Uplifting, modern, instrumental (think corporate explainer vibe)
- **Sound Effects**: Subtle notification pings, water sounds (Scene 1), clock ticking (Scene 2)
- **Audio Levels**: Voiceover -3dB, Music -18dB, Effects -12dB
- **Total Audio Mix**: Balanced, voiceover always clear and primary
