# Municipal Water Fault Video - Complete Production Package

## 📋 PROJECT OVERVIEW

This comprehensive production package contains everything needed to create, produce, and distribute a professional educational video about reporting water faults to South African municipalities without creating duplicate complaints.

**Project Duration**: 2-16 weeks (depending on production method)  
**Video Length**: 3-4 minutes  
**Target Audience**: All South African residents (ages 16+)  
**Key Message**: "Keep your reference number and use it to follow up—don't create duplicate complaints"

## 🎨 KEY CREATIVE ELEMENTS

### Main Message
"Keep your reference number and use it to follow up—don't create duplicate complaints."

### 8 Scenes
1. **The Problem** - Resident reports water fault, receives reference number
2. **The 48-Hour Confusion** - Clarify what 48-hour response time means
3. **The Common Mistake** - Show what happens when complaints are duplicated
4. **The Timeline** - Visualize how duplicates create confusion
5. **The Correct Way** - Show proper follow-up using original reference
6. **48 Hours Passed** - What to do if fault unresolved after 48 hours
7. **Recurring Fault** - Report recurring faults, don't start fresh
8. **Paper Trail** - Reference number documents the entire journey
9. **Final Call-to-Action** - Diverse residents committing to correct procedure

### Color Scheme
- 🟢 **Green (#2ECC71)**: Correct actions, positive outcomes
- 🔴 **Red (#E63946)**: Mistakes, warnings, what NOT to do
- 🔵 **Blue (#3498DB)**: Information, authority, municipality
- ⚪ **Gray (#95A5A6)**: Neutral, waiting periods
- 🟡 **Gold (#F39C12)**: Emphasis, reference numbers

## 💡 KEY PRODUCTION PRINCIPLES

1. **Simplicity First** - Prioritize character expressions and text clarity over complex backgrounds
2. **Mobile Optimization** - Test all content at small screen sizes
3. **Accessibility** - Captions, high contrast, readable fonts are non-negotiable
4. **Consistency** - Use the same reference number format throughout
5. **Timing** - Voiceover drives animation timing, not the other way around
6. **Emotion** - Color and character expressions convey emotional journey
7. **Testing** - Quality assurance is built into every phase, not just the end
8. **Feedback** - Regular stakeholder check-ins prevent major revisions

---

## ⚠️ COMMON PITFALLS TO AVOID

- ❌ Making the 48-hour message ambiguous (BE EXPLICIT)
- ❌ Overcrowding scenes with unnecessary details
- ❌ Inconsistent reference number formatting
- ❌ Text too small to read on mobile devices
- ❌ Character emotions unclear or too quick
- ❌ Ignoring South African context in settings/characters
- ❌ Poor audio sync between animation and voiceover
- ❌ Assuming video will go viral without promotion
- ❌ Not testing for color blindness issues
- ❌ Losing the core message in creative flourishes
